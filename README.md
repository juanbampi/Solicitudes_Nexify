# 📊 Análisis de Solicitudes - Dashboard en Power BI
Este proyecto presenta un dashboard avanzado de análisis de solicitudes, diseñado para facilitar la evaluación de volúmenes, variaciones y eficiencia operativa en la gestión de solicitudes. Utiliza segmentadores dinámicos y visualizaciones intuitivas para extraer insights clave.

## 🧾 Descripción del proyecto
El objetivo fue analizar la evolución y distribución de las solicitudes recibidas a lo largo del tiempo, evaluando cambios año a año y permitiendo una lectura clara de los datos según distintas dimensiones como prioridad y categoría.

## KPIs principales
✅ Total de solicitudes con su variación porcentual interanual

📈 Promedio de solicitudes y su variación %

📊 Cantidad de solicitudes y su variación %

## Segmentadores generales
📅 Año

📂 Categoría

🚨 Tipo de prioridad

## 📈 Visualizaciones incluidas
Gráfico combinado de evolución y variación: líneas para la evolución mensual + barras para la variación absoluta respecto al año anterior.

Promedio mensual de solicitudes: gráfico de barras por mes y año.

Top 5 de gestores: gráfico de barras horizontales.

Estado de solicitudes: gráfico de torta.

Cantidad por prioridad: gráfico de barras horizontales según tipo de prioridad.
